# 🛒 Ecommerce MERN Project

A full-stack **Ecommerce Web Application** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.  
This project includes a **customer shopping website, admin dashboard, and backend API**.

---

# 🚀 Features

### 👤 User Features
- User Registration & Login
- Browse Products
- Product Details Page
- Add to Cart
- Checkout System
- Order Management

### 🛠 Admin Features
- Admin Dashboard
- Add Products
- Edit Products
- Delete Products
- Manage Orders
- Manage Categories

---

# 🧰 Tech Stack

### Frontend
- React.js
- React Router
- Axios
- Tailwind CSS / CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Other Tools
- JWT Authentication
- REST API
- Git & GitHub

# ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Wishwas-Meghawal/Ecommerce-MERN-Project.git
```

---

### 2️⃣ Install Dependencies

Frontend

```bash
cd e-commerce
npm install
```

Admin

```bash
cd admin
npm install
```

Backend

```bash
cd server
npm install
```

---

# ▶️ Run Project

Frontend

```bash
npm start
```

Admin

```bash
npm start
```

Backend

```bash
npm run dev
```

---

# 🌐 Environment Variables

Create `.env` file in **server folder**

Example:

```
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
